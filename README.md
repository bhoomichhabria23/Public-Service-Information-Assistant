# Public Service Information Assistant

The Public Service Information Assistant is an AI-powered web application designed to help citizens easily understand government schemes and public services.

The system allows users to search for government schemes, check eligibility, ask questions through an AI-powered chatbot, and contact the support team.

## Features

* User registration and login
* Government scheme information
* Scheme search and filtering
* Eligibility checking
* AI-powered chatbot
* User dashboard
* Contact form
* Email notifications
* Responsive user interface
* MongoDB Atlas cloud database
* REST API-based communication
* GitHub-based version control
